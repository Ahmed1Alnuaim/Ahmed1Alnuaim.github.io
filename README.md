# ahmedalnuaim.com

Personal page for Ahmed Al-Nuaim. One static `index.html`, no build step.

- Run locally: `npm run dev`, then open http://localhost:5173
- Publish: push to `main`; GitHub Pages serves the repo root at ahmedalnuaim.com (see `CNAME`).
- `og.jpg` is the link-preview image (1200×630). Regenerate it if the name, title or photo changes.
- To add a CV, drop `cv.pdf` here and uncomment the CV line in `index.html`.
